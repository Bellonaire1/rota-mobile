# Rota

Rota is a team shift-scheduling mobile application for small businesses such as restaurants, clinics, and retail teams.

Built for the Dev and Design HQ Product Design and Engineering Bootcamp Final Graduation Task.

## Current status

Foundation scaffold.

## Structure

- app — React Native / Expo mobile app
- server — Node.js / Express API
- docs — project documentation and architecture decisions
- load-tests — k6 scripts and reports

## Stack

### Mobile
- React Native
- Expo
- TypeScript
- Expo Router

### Backend
- Node.js
- Express
- TypeScript
- Prisma
- PostgreSQL
- Zod

## Current API

GET /api/v1/health

No authentication required.

More architecture, security, state, sharding, testing, and deployment documentation will be added as the project develops.
